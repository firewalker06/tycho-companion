# Windows test build

Extract the attached ZIP, then run `TychoCompanion.exe`.

This is a portable x86_64 test build using the Godot 4.7.2 Windows runtime and the packed local demo. It makes no network requests and has no configuration or token support. Press `I` to enter Inspect mode for 15 seconds and `Esc` to leave it.

It is not signed as Tycho Companion, so Windows SmartScreen may ask for confirmation. Do not use it as a production install.
